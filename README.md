# Инженерный колледж — статический многостраничный сайт

Учебный проект-брошюра для демонстрации HTML5, CSS3, Bootstrap 5 и чистого JavaScript. Сайт адаптивный, использует общий стиль и фиксированную верхнюю навигацию.

## Карта страниц
- `index.html` — главная, слоган и призывы к действию.
- `programs.html` — направления обучения и фильтр карточек.
- `admissions.html` — этапы поступления и пример стоимости.
- `life.html` — студенческие клубы и пример объявлений.
- `contacts.html` — контакты-примеры и форма обратной связи.
- `registration.html` — предварительная регистрационная форма.

## Реализованные функции
- Bootstrap 5 responsive navbar, сетка, формы и компоненты.
- Фиксированная сворачиваемая навигация, активные ссылки, skip-link.
- Фильтрация программ по категориям (JavaScript).
- Клиентская проверка регистрации: required, email, телефон, совпадение паролей, дата не в прошлом, обязательное согласие.
- Контактная форма с проверкой и honeypot-полем для простой защиты от спама.
- Сообщения о результате отправки, доступные через `aria-live`.
- Семантические HTML-элементы, подписи полей, состояния фокуса, reduced-motion.

## Ограничения
- Сайт статический; данные форм не отправляются и не сохраняются на сервере.
- Контактные данные, события и цены обучения являются демонстрационными и не официальными.
- Формы показывают локальное подтверждение в браузере; для реальной отправки требуется серверный или сторонний endpoint.
- Bootstrap и шрифты подключаются с CDN, поэтому для их загрузки требуется интернет.
- Антиспам реализован только простым honeypot-полем и checkbox, не является полноценной серверной защитой.

## Авторство и ресурсы
- HTML, CSS и JavaScript созданы для этого учебного макета.
- Bootstrap 5.3.3: https://getbootstrap.com/ (MIT License), подключен через jsDelivr CDN.
- Google Fonts — DM Sans и Manrope: https://fonts.google.com/ (шрифты SIL Open Font License).
- Визуальная иллюстрация на главной сделана средствами CSS; сторонние изображения не используются.

## Запуск и навигация
Открой `index.html` в браузере. Для навигации используй верхнее меню. Программы, поступление, студенческая жизнь, контакты и регистрация доступны как отдельные HTML-страницы.

## GitHub Pages
Опубликуй содержимое корневой папки репозитория через GitHub Pages (Settings → Pages → Deploy from a branch → `main` → `/ (root)`). После публикации добавь URL сайта сюда:
- GitHub repository: `https://github.com/<your-username>/<your-repository>`
- GitHub Pages: `https://<your-username>.github.io/<your-repository>/`
